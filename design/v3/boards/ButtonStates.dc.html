Button states

Every button answers a press on the button itself, and one that starts slow work stays busy until the work is done. One rule for every kind, theme and accent.

When to show which
Pressed, on every button

In 60 ms, out in 150 ms, so even a quick click shows. No ripple. The text colour is the overlay, so a dark-text primary darkens and a light-text default lightens, in either theme and with any accent.

Working, only when the action waits

On disk, network or the game: install, update, check, restore, delete, launch. Show it once the action has run 200 ms, then keep it at least 500 ms so it never flickers. Instant actions, like opening a folder or a page, never show it.

When it's done

The button goes back to rest. What happened shows where it lands: the row, the label, or a notification. A failure is a notification too, never a red button.
