# Zenith v3

The v3 redesign: every screen, dialog and overlay of the Zenith UI, plus the foundations they share (tokens, colour directions, button states). It is the target for the rework planned in [`docs/v3-rework-plan.md`](../../docs/v3-rework-plan.md).

How to open, use and render it is in [`design/README.md`](../README.md). In short: serve the repository root, open `/design/?set=v3`, and render with `node design/tools/render.mjs v3`.

The portraits and logos are the app's own files in `mod_manager_flutter/assets/characters/` and `mod_manager_flutter/assets/brand/`; the boards link to them rather than keeping copies.
